---
name: learned-judge-addendum-scoped-delivera-8ccb
description: When scoring a "final" deliverable that was requested via an addendum/correction to an earlier draft — check whether each addendum item actually landed in the final text.
---

1. Extract every explicit change the addendum asks for, as a numbered checklist (corrections to rules/tables, named items to list, reminders to apply). Treat each as a separate pass/fail row.
2. Search the work text itself for each row — do not accept a summary, a promise, or the agent's claim that it "applied" the correction. If a rule table is quoted, compare it character-by-character with the corrected version in the addendum.
3. Cross-check the transcript of the producing run (transcript keyword search, scoped to that run id) for the corrected terms. A correction appearing in the COO/parent brief but not in the producing agent's final text is a fail, not a pass.
4. Watch for the common failure mode: the agent re-files its pre-addendum draft with only the easiest reminder applied, while the substantive correction is silently dropped. Quote the stale text as evidence.
5. Check the base deliverable separately so the score reflects both what was asked newly and what was already required; state the split in `why`.
6. Name the capability gap at the level of the failure: failure to apply a supplied correction is an instructions/method gap, not a knowledge gap — reserve "knowledge" for errors the agent had no way to know were wrong.
