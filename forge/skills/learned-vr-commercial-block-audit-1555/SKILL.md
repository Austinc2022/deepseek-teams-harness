name: learned-vr-commercial-block-audit-1555
description: When critiquing a GAME.md / store thesis / price thesis on a critique panel or demand gate, through the market lens.
---

1. Hook test: is it ONE sentence? Does it name the mechanism and at least one category keyword (gravity, hand-tracked, VR, puzzle) a shopper scans for? Flag metaphor-only hooks ("dark worlds") as taglines, not store hooks. Check the hook against the pixels and the measured content for overclaim.
2. Buyer test: audience must be a persona + purchase trigger (e.g. the Cubism/Puzzling Places buyer), not a comfort spec ("seated") and not an adjacent genre that invites unwinnable comparisons ("music games" pulls in the Beat Saber crowd).
3. Genre test: the peer set must include the best-in-class title. Per row record: platform, price, count, instrument (Quest RATINGS vs Steam written REVIEWS - never one column without an instrument note), fetch date, verified/unverified. Compute the best-comparable parity case: ratings x review-to-buyer factor (110 median) x net price, and compare it to the revenue target. If parity with the best comparable still misses the target by >3x, say so.
4. Price-vs-content test: run the same-price head-to-head (e.g. $9.99 buys Cubism's 90 authored puzzles vs our built minutes). The price must be set against BUILT content, planned content labelled PLANNED. Warn about refund/review-score risk when built minutes are tiny.
5. Sales-path test: units = target / net price; express as % of platform MAU. Every funnel input (demo plays, wishlists) must name an acquisition channel (itch.io / SideQuest / App Lab demo / featuring / UA) and label rates ARGUED. Compare the funnel's best cell to the units needed.
6. Honest-claims test: MEASURED today / PLANNED not built / NOT claimable must all be present; cross-check one claim against evidence files and one screenshot.
7. Spot-check all arithmetic with the vr_sales_path_calculator tool.
Mistakes to avoid: trusting unverified store counts from partial page reads; mixing ratings and reviews; letting "seated" stand as an audience; accepting a funnel with no channel; letting planned content carry the price; judging by effort spent.
