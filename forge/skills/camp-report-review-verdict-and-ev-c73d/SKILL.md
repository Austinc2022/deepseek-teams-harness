# Report review: verdict and evidence discipline

1. **Requirements first.** List every named criterion or requirement with a one-line answer before any detail. Nothing is lost if the output is cut, and no item is quietly skipped.
2. **Quote -> classify -> verdict.** For each criterion: gather the quotes, classify the evidence, then write the verdict. The verdict must follow from the quote and one-line reason in the same breath. If your reason contains a 'but' that flips the criterion, the verdict is wrong - fix the verdict, not the evidence.
3. **Judge the report, not the idea.** A weak product or a dubious concept is not a report defect; a weak report is. Grade the criterion exactly as written. When a criterion is met, state plainly that it passes; never manufacture a defect to balance the review.
4. **Evidence ladder.** Label every figure and claim: observed paid (PO, invoice, price paid, signed contract, renewal) > paid comparable (price points, review counts, regions) > vendor list price > estimate with stated method > guess. A vendor list price carrying an 'observed' tag is a mislabel: call it a list price and flag the mislabel itself as the defect.
5. **Marketing vs procurement.** Vendor case studies, sponsored research and vendor blogs are marketing collateral, not procurement evidence. Name them as such, and say which procurement proof is absent: budget line, PO/invoice/price paid, signed contract, renewal, pricing outside the named region, payer-side interviews.
6. **Dates.** A source with only an accessed date and no publication date is undated - flag it. Publisher plus year is dated. Report the count of sources carrying both a URL and a real date.
7. **De-duplicate sources by origin.** The same blog, publisher or dataset split across several bibliography entries is one source. Count unique origins before crediting volume; entry count is not evidence volume.
8. **Outreach test.** Interviews, pilots, demos to prospects, direct emails and self-run audience surveys are all market contact even when described as research. If the criterion forbids outreach, flag every instance and require the derived data to be excised, not relabelled.
9. **Unverified claims.** Enumerate inline claims the source list does not carry, in their own list.
10. **Rank defects by money impact.** Order the defects by how much each would distort the investment decision, each with a minimum fix tied to the quote it came from. Before sending, re-read every issue and delete anything not tied to a quote.

Final check: every criterion answered; verdicts match their own reasons; passes stated as passes; evidence labels present on every figure; no invented defects.
