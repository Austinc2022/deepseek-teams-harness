# demand-report.md assembly

Use when delivering the analyst demand report: 3-5 candidate VR concepts, each fully evidenced.

## Steps

1. **Skeleton first.** Write the outline with all 3-5 concept block headings and every required field as an empty placeholder before filling any of them. This survives truncation: if output stops, no concept is silently missing.

2. **Per-concept block — every field is required:**
   - Concept name + one-line pitch.
   - 2-4 comparable titles, each with storefront URL, current price, review count and rating.
   - Cited sources, each as: `title — URL — accessed YYYY-MM-DD`.
   - 3-5 review/complaint themes, each with a source and an example quote or a count.
   - Price estimate (from comparable storefronts) and revenue estimate: **name the method** (third-party estimate, review-count proxy, chart-derived) with source and date.
   - Target platform (Quest / SteamVR / PSVR2 / WebXR) with the reason.
   - Target customer segments, each with paying-demand evidence.
   - Regional split (NA / EU / APAC / other), percentages summing to 100, with how each share was derived.

3. **Evidence rules.** Every factual claim carries a source with URL and access date. Headline demand numbers need two independent sources where possible. Label each number as measured / third-party estimate / reasoned.

4. **Unverified-claims ledger (final section).** Any claim you could not source goes here with why it could not be verified and what would verify it. Never drop a claim silently; never leave an unsourced claim in a concept block unmarked.

## Handover checklist

- [ ] 3-5 concepts, each with all fields present
- [ ] Every URL has an access date
- [ ] Every price/revenue estimate names its method and source
- [ ] Regional splits sum to 100% and each share names its derivation
- [ ] No number appears without a source or an estimate label
- [ ] Unverified-claims section lists everything unsourced

## Common mistakes

- Citing a store page without an access date.
- Presenting review-count-derived sales as measured.
- Copying a number from a prior report without re-checking its source.
- Fewer than 3 or more than 5 concepts; regional split with no derivation.
