---
name: learned-skill-safety-and-rule-audit-44d2
description: Whenever you must judge a skill/proposal/guidance document before it is published to agents — checking it against the company hard rules (no running downloaded code, no data egress, no orders, no weakening of checks or honesty) and verifying its factual anchors.
---

1. Read the given text for hard-rule violations first: any instruction to download/execute external code, send data off-machine, buy/order/contact anyone, bypass a gate, edit evidence after write, or claim unmeasured things as measured. Weakenings are often subtle — look for tolerances that admit the known defect, assertions that pass by coincidence, or "PASS with null" style exits.
2. Find the published file(s): glob the forge/skills and agent-homes trees for the skill name or distinctive phrases. Compare the on-disk text with the text you were given; stale variants can carry older, wrong guidance (e.g. a wrong-direction timestamp assertion). Note any frontmatter name/directory mismatches.
3. Verify every anchor claim against the real tree it cites (file:line for code behaviour, quoted measurements in evidence files). Line numbers drift — verify the mechanism (who stamps what, in what order) by reading the code, not just the line match. If the cited ticket/tree id is not on disk, search work directories for the matching artifact set.
4. Resolve every cited fact id: knowledge_get + knowledge_search + transcript_search. A fact that "is not available (not a measured fact)" may still exist as an argued record in transcripts — say which it is. The claim itself must be independently verified from code/measurement regardless of the citation.
5. For timestamp/counter comparison checks in the skill: derive the true order from the code that stamps each side and confirm the skill's direction and tolerance separate the measured correct case from the measured defect signature. Reject one-way assertions that pass only on same-ms coincidence, and tolerances wide enough to admit the defect.
6. Judge against the rubric only, not effort. Mark safe only if all four hard rules hold; list each rule as its own reason with the evidence and its strength (measured / transcript-corroborated / argued). Put citation-hygiene defects (unresolvable fact ids, stale variants, drifted line anchors) in the report as caveats even when they do not flip the verdict.
7. If a recorded fact is actually wrong or outdated, knowledge_flag it with the evidence; if the id does not resolve as a measured fact, report it in the verdict instead of flagging a phantom id.
