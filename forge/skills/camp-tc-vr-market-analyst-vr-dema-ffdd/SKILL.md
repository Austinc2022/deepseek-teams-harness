description: When judging whether a VR/Quest concept's demand evidence justifies approving a build, before writing a verdict memo.
---

1. Apply the payment bar: an item counts only if it shows money already spent — what was bought, at what price, how many units/ratings, which regions. Interest signals (views, likes, comments, petitions, polls of "would buy", surveys of "want", wishlists) are logged but weighted zero.
2. For each evidence item, write two lines: "shows:" and "does not show:". Never let a like count stand in for a transaction.
3. Watch for model mismatches: a poll testing an upfront $9.99 buy does not validate a free-to-install + paid-pack plan; a free comparable (e.g., Bogo) validates engagement only, never payment.
4. Watch for platform/context mismatch: AR/mobile crowdfunding backers (e.g., ~$45/backer) prove a niche pre-pays for a promise on a different platform, not Quest-scale demand.
5. Build the counter-comp table from read-only store data: queststoredb.com / Meta Horizon Store listings for the direct category — record price, rating count (units proxy, label as estimate), release date, regions. Compare like-for-like gameplay loop (raising/bonding vs grooming/roleplay are different segments).
6. State flip evidence concretely: rating thresholds on paid same-platform comps, published paid-DLC/IAP attach rates, regional sales splits — each with where to find it.
7. Name the cheapest read-only desk step (usually the comps table) and the least-supported part of the commercial plan (usually the monetization conversion, which interest metrics never measure).
8. Keep the verdict binary and unsoftened; write the memo under the word cap.
