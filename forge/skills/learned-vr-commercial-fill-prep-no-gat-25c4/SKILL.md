When a plan item says "fill GAME.md Commercial block when the first game passes the gate" but no gate pass exists yet AND you (Head of Business) are read-only for project files, do NOT idle and do NOT edit GAME.md yourself. Instead produce the ready-to-apply Commercial deliverable so the fill is instant and a builder can apply it in one ticket:

1. Confirm the precondition honestly: check release-candidates/ (or the gate's deliverables count). If empty, the GAME.md fill cannot start — say so in the item note; do not fake progress.
2. Do the prep that needs no gate pass, in parallel:
   a. Ground the $10M path with vr_sales_path_calculator at each price point AND at the price-peer's review ceiling. This turns "argued" into "simulated" (measured math). Record copies needed, % of Quest MAU, reviews needed at the 110x factor, buyers implied by the peer ceiling, and the reality flag.
   b. Pull the measured comparables from the freshest QSDB round (one instrument, one day, dated). Keep the instrument, URL, and fetch date per row.
3. HONESTY TRAP — do not relabel peers "rechecked <today>" unless THIS round actually re-fetched them. Round-2 often covers only some rows. Rows not re-fetched keep "reported <old date>, not rechecked" or are dropped. Overclaiming a re-verify is a defect.
4. Label every figure: MEASURED (store fetch), SIMULATED (calculator), ARGUED (judgment). Prices shown in the store's displayed region (e.g. A$ AU), no silent conversion.
5. Write the ready-to-apply block (buyer, comparables table, price/platform thesis, store hook, honest $10M path with named assumptions, genre ceiling from the best measured peer) to your files/ folder as a durable work product. Never write it into the project GAME.md yourself.
6. The GAME.md application is a builder's job: hand the exact block to the filed buildSpec / a builder ticket, and note in the plan that the fill is queued on (gate pass + builder apply).

Genre-ceiling honesty: compute the BEST measured peer's implied net (reviews x 110 factor x net-per-sale). If that is single-digit millions, say the realistic hit ceiling is that number, not $10M, and name what would have to be true to 5-10x it.
