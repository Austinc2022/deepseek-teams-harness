Use when writing the trailer and key art briefs for a store package (store-package/creative/).

1. Gather inputs first: product marketing positioning, target segment from the launch plan, and the final store listing copy. A brief must not introduce a message the listing copy does not support.
2. Look up the CURRENT Meta Quest store asset specifications via websearch (Meta developer documentation): resolutions, aspect ratios, file formats, safe areas, text-overlay rules, trailer lengths. Do not hardcode specs from memory — record in each brief the spec source and date checked.
3. For each region and language, write two briefs:
   - Trailer brief: objective, target audience, required shots (gameplay capture priority, comfort/motion notes), tone, mandatory elements (platform, comfort rating if applicable), localized text/VO plan or an explicit 'text-free master' decision, length cutdowns (e.g. 15/30/60s).
   - Key art brief: concept, composition and safe-area constraints per spec, logo lockup, localized text variants or text-free decision, regional cultural flags (symbols, colors, gestures).
4. In every brief, add: deliverables list with specs, owner, deadline, and approval path.

Verify before handover:
- [ ] Every region has both a trailer brief and a key art brief — no region is an unannotated copy of the base.
- [ ] Every spec cited has a source and date checked.
- [ ] Messaging in briefs matches the store listing copy for that region.
- [ ] Localization decisions (text-free vs. localized variants) are explicit per region.
- [ ] Regional cultural flags are written as open questions for the owner where uncertain, not assertions.
