description: When reviewing a pricing/live-ops proposal for a game or app where the input packet mixes real data (surveys, demo tests) with unsourced planner claims, and you must produce price, purchases, event calendar and revenue arithmetic that stay mutually consistent.
---

1. Evidence ledger first: table every fixture claim as supported / stated-intent (upper bound only) / unsourced. Never let an unsourced number (e.g. TAM, conversion %) enter the revenue model; name it and exclude it.
2. Price: anchor on the price point the demand data actually tested, plus 1-2 real competitor prices. Build a regional table with 5+ markets: US anchor, EU VAT-inclusive parity, PPP-discounted emerging markets (~50-60% of US). State FX assumptions explicitly and a reprice cadence for high-inflation currencies. Answer the "single FX-converted price" question explicitly (no: PPP, store convention, grey markets, tax display, psychological price points).
3. Purchases: write an allow-list and a reject-list before judging items. Hard rejects: anything affecting score/rank/unlocks, fake scarcity (resetting counters, lying countdowns - EU Omnibus/FTC exposure), never-again exclusivity, loot boxes. Give each proposed item a yes/no with severity-ordered reasons; offer a compliant replacement, do not just reject.
4. Calendar: fixed staff budget (compute hours: FTE x weeks x 40h), then a week-by-week table (event / player benefit / cost-hours) summing under budget with a deliberate buffer. Every event open to all base-game owners; paid items are additive cosmetics, permanent store entries.
5. Revenue model as a script (reproducible): per-unit chain (blended ASP from regional mix x (1-refund) x (1-platform fee)) -> unit range from an external anchor (category leader sales x plausible share %), cross-checked against survey funnel with intent-to-purchase haircut -> launch decay split -> daily ranges per week + steady-state monthly range (one-off tail + cosmetic attach on MAU).
6. North-star test: compute units/day the headline target needs, compare to category-leader lifetime totals. If it exceeds them, say not supported and list the specific evidence (wishlists, featuring commitments, comparable actuals, sourced TAM, recurring ARPPU) that would change it.
7. Consistency pass: every figure in prose must trace to the script or the price table; re-run the script and diff. Watch arithmetic gotchas: VAT inside gross, day-vs-month factors, x10 audience claims that silently assume recurring spend from one-off purchases.
