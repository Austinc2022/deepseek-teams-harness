Audit procedure for a store package plus supporting demo evaluation:

1. Build a claim matrix: extract every assertion in the team summary (regions covered, evidence-based, nothing submitted or bought) and mark each verified or contradicted by the artifacts. Never accept the summary at face value.
2. Coverage check: list the plan required regions/languages, then diff against the package file manifest AND price rows AND localisation notes. Missing items are defects unless the package explicitly lists them as gaps. Silence (e.g. No other notes) is not gap disclosure.
3. Claim-vs-build check: extract every factual claim from each listing (framerates, features, press quotes) and match against the plan/build facts. Any feature the build does not have, any review that cannot exist (no player study = no reviews), and rounded numbers presented as flat guarantees are invented or overstated claims.
4. Price check: every row must be marked draft and carry reasoning genuinely tied to the evaluation. Flag final labels without owner approval, reasoning that contradicts the evaluation, and rows with no reasoning.
5. Flags check: machine-translated copy must be flagged as needing native review (identified as MT is not enough); every compliance item must be flagged for lawyer review.
6. Action/outreach check: read owner-actions and status for any submission, publishing, spending, or outreach. Verify the team claim matches what the package itself records (e.g. a purchased ad voucher contradicts nothing bought). Clarify who acted (owner vs team) and note charter limits on team spending.
7. Demo-eval check (where relied on): each plan criterion needs an honest pass or fail with evidence; a not-run criterion must never be scored PASS. Fun needs its own verdict plus a plain statement that an internal test cannot prove fun or willingness to buy. Comfort risks (locomotion, motion, scale) must be addressed. Keep/change/cut recommendations must cover every feature.
8. Quote offending text verbatim in defects, name the broken criterion, and state the concrete fix. Separately list what is genuinely correct. Do not invent defects the evidence does not support.
