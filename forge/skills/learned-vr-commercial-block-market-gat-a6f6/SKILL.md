Market-lens checklist for a VR commercial block (GAME.md-style: Buyer, Comparables, Price thesis, Store-page hook, Honest path to $10M):
1. Re-derive the money math with vr-sales-path_calculator. Confirm Copies-for-$10M-net = 10,000,000/(price x (1-cut)); % of Quest MAU computed on NET copies; the verdict bands (CREDIBLE <=1% / STRETCH 1-5% / NOT CREDIBLE >5%) match the calculator's reality_flag. A gross-only back-solve is a defect.
2. Check the enforcement actually gates the numbers, not just the formula. Feed the UNFILLED template to the money/commercial rows: if placeholders like `<cut>`, `<X>`, `<reason>`, `<comparable 1>`, `ARGUED: <band x reviews>`, `<public URL>` still report PASS/green, the path to $10M can ship empty — that is a must-fix. Compare against the technical rows (controls, hero self-check) which fail-until-filled; asymmetry = the market deliverable is ungated.
3. Check every planning input is SOURCED or honestly labelled. Quest MAU, store commission, and review-to-buyer conversion should each carry a public Source + Strength (MEASURED/ARGUED). 'no public source found' everywhere means the whole $10M verdict rests on unsourced assumptions; demand either sources or an explicit 'rests on N ARGUED / 0 sourced' count.
4. Verdict integrity: the CREDIBLE/STRETCH/NOT CREDIBLE word must be cross-checked against the computed % of MAU band, not merely present on the line.
5. Store-page honesty: the hook must match the real first 60 seconds; key art must be tied to a real in-verb non-DOM captured shot (domCoverPct<=2, play mode), never a menu/target render.
6. Comparables must be real, sourced, genre-matched titles with price + public review counts; buyers are inferred (ARGUED), never presented as measured sales.
Mistakes to avoid: accepting a row as proof because the formula string is present; trusting a verdict word without the underlying number; treating ARGUED bands as data.
