CLI workbench

Each session gets its own git worktree on a new branch wb/<id> under forge/worktrees/, so sessions never edit the same files. Sessions keep running when you leave this page.
Each account is a separate login (for example a different subscription plan) with its own private config folder. Add one, press Log in, finish the login in the terminal that opens, then close that tab. "My normal login" is the one you use in your own terminal.
